GETTING STARTED / LOCAL SDK BETA

Your first verified
continuation.

The playground explains the idea. The downloadable SDK runs it in a local workspace on your Mac.

Beta distribution is being prepared.

Checkout is not open yet. These steps describe what to do once you have the beta bundle.

01. Check your setup

You'll need an Apple Silicon Mac, Node.js 22.19–22.x, npm, and Git. Start with disposable work. The beta supports one local workspace and one writer.

02. Verify and install the bundle

Open START-HERE.html inside your delivered ZIP. It explains how to compare the ZIP fingerprint and independent public key before installation. Then install the package in a new empty test folder:

npm install --prefix . --offline --ignore-scripts \
  --package-lock=false --no-audit --no-fund \
  "/absolute/path/to/bundle/packages/trajecta-beta-0.1.0.tgz"

./node_modules/.bin/trajecta-beta version
./node_modules/.bin/trajecta-beta demo --state-root ./demo-state

The demo rejects a stale handoff, accepts the current one, and retries it without advancing twice.

03. Verify your installation

The delivered guide has the complete verify-acceptance command, with your ZIP, fingerprint and output paths. A successful run prints ACCEPTANCE_PASSED and saves an evidence file you can inspect.

On macOS, use canonical paths: /private/tmp rather than /tmp. Choose fresh state and evidence directories for each test.

04. Continue your own work

Use a disposable Git workspace with a commit, an attached branch, and an origin remote. Run doctor, create a target card with host init, then follow the bundle's three recipes for a manually transferred JSON handoff.

A target card is private and expires after 30 minutes. Keep it out of public posts and support emails.
