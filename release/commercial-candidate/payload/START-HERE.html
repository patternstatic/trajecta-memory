Trajecta checks whether a local handoff still matches its work, branch and target. Stale work stops. Current work resumes once. An equivalent retry returns the same receipt.

This is a local SDK, not an automatic ChatGPT-to-Codex connector. Nothing here posts, contacts an AI service or executes instructions inside a handoff.

Before you start

You need an Apple Silicon Mac, Node 22.19–22.x, npm, Git and a new disposable test folder.

Compare the ZIP SHA-256 with shasum -a 256 "/path/to/download.zip". Obtain both the digest and seller public key separately from the ZIP.

The key fingerprint is SHA-256 of SPKI DER, not the PEM file hash. The exact copyable Node command is in the plain-text guide. Stop if either value differs.

Install and run the proof

npm install --prefix . --offline --ignore-scripts --package-lock=false --no-audit --no-fund "/absolute/path/to/bundle/packages/trajecta-beta-0.1.0.tgz"
./node_modules/.bin/trajecta-beta version
./node_modules/.bin/trajecta-beta demo --state-root ./demo-state

Expect STALE (3 → 3), CURRENT (3 → 4), then RETRY with identical receipt bytes and revision 4.

Verify the installed delivery

Use canonical absolute paths with no symbolic-link components. On macOS use /private/tmp, not /tmp. The parent folders must exist; the new state and evidence directories must not.

/absolute/path/to/test/node_modules/.bin/trajecta-beta verify-acceptance \
  --archive /absolute/path/to/original-download.zip \
  --pinned-zip-sha256 <independent64hex> \
  --bundle-root /absolute/path/to/unpacked/trajecta-verified-resume-sdk-beta-0.1.0 \
  --public-key /absolute/path/to/independent-public.pem \
  --state-root /absolute/path/to/new-acceptance-state \
  --evidence-dir /absolute/path/to/new-acceptance-evidence

Success prints ACCEPTANCE_PASSED. It proves local behavior and archive integrity, not payment, human usability or remote task completion.
