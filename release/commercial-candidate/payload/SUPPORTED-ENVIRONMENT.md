# Supported environment

- Apple Silicon Mac
- Node.js 22.19 through 22.x (`>=22.19 <23`)
- npm and Git available in Terminal
- one local workspace and one active Trajecta writer
- a manually transferred, user-controlled JSON handoff file
- English command output and documentation

This commercial candidate does not connect ChatGPT or Codex accounts. A
successful receipt proves the local state transition, not completion of the
next action by an AI. Windows, Linux, Intel macOS, hosted sync, multi-writer use,
unattended resume and automatic client adapters are not included.
