# If a step stops

- UNSUPPORTED_ENVIRONMENT: use an Apple Silicon Mac with Node 22.19–22.x. Doctor also needs an attached Git branch and an origin remote.
- TARGET_EXPIRED: create a new target card and regenerate the handoff.
- REVISION_CONFLICT: inspect current work and export a fresh packet. The rejected attempt did not advance work.
- USER_ACCEPTANCE_REQUIRED: inspect the handoff before running resume with --accept.
- OPERATION_IN_DOUBT: preserve the local state and stop modifying it. Report the code and step; do not delete journals to force a retry.
- npm ENOENT: confirm the absolute tarball path exists and use a new test folder.

The demo needs a new or empty private state directory. Re-run it with a new directory name. Existing receipts belong to the previous run.
