Before you start

You need an Apple Silicon Mac, Node 22.19–22.x, npm, Git, and a new folder for testing. Keep real work and secrets out of the first trial.

Compare the ZIP SHA-256 and seller key fingerprint with the separate values supplied with your download. A key inside the ZIP cannot establish its own origin. If values differ, stop.

1. Install the local package

Open Terminal in a new empty test folder. Replace the archive path below with the full path to the package inside this unpacked bundle. Keep the quotation marks if the path contains spaces.

npm install --offline --ignore-scripts --package-lock=false --no-audit --no-fund "/absolute/path/to/bundle/packages/trajecta-beta-0.1.0.tgz"
./node_modules/.bin/trajecta-beta version

Expected: Trajecta Verified Resume SDK Beta 0.1.0. Installation uses the package on disk, has no dependency downloads, and does not change your shell startup files.

2. Run the isolated proof

./node_modules/.bin/trajecta-beta demo --state-root ./demo-state

Read the three outcomes:

  • STALE: rejected; revision stays 3.
  • CURRENT: accepted; revision advances from 3 to 4.
  • RETRY: the same receipt bytes; revision stays 4.

Receipts remain in demo-state. Use a new state-folder name for another trial. This isolated example is not evidence that your own project or an external AI completed work.

3. Run the installed acceptance check

Use the original downloaded ZIP, the separately unpacked bundle, and the SHA-256 pin and public key you obtained independently. Run the installed package from outside a source checkout. Both output paths must be fresh absolute paths whose parent folders already exist.

/absolute/path/to/test/node_modules/.bin/trajecta-beta verify-acceptance \
  --archive /absolute/path/to/original-download.zip \
  --pinned-zip-sha256 <independent64hex> \
  --bundle-root /absolute/path/to/unpacked/trajecta-verified-resume-sdk-beta-0.1.0 \
  --public-key /absolute/path/to/independent-public.pem \
  --state-root /absolute/path/to/new-acceptance-state \
  --evidence-dir /absolute/path/to/new-acceptance-evidence

A successful run prints ACCEPTANCE_PASSED and the evidence file path after all 14 automated behavioral checks pass. Acceptance item #15 remains an independent operator observation; the command does not simulate it. This evaluation result is not commercial approval and does not activate a sale.

4. Check a local workspace

Open a Git workspace with at least one commit, an attached branch, and an origin remote. Invoke the installed command using its full path:

/absolute/path/to/test/node_modules/.bin/trajecta-beta host init --out target.json

Check the repository and branch it displays. The target card is private, expires in 30 minutes, and is single-use. Do not post it or send it to support.
