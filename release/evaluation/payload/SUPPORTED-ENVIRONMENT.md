# Supported environment

Apple Silicon macOS; Node >=22.19 <23; Git workspace with an attached branch and origin remote; one writer at a time. State stays on the local machine. The release installation check uses npm 10.9.8.

This evaluation uses JSON files to carry handoffs. It does not connect ChatGPT or Codex accounts. A successful receipt proves the local state transition, not completion of the next action by an AI.
